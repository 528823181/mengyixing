# 蒙益行 · 智游内蒙古

北疆文旅公益项目「蒙益行」的网页端：一个可以点开、走进去、还能盖章领证书的十二盟市数字志。

纯静态站点，无构建步骤，双击 `index.html` 即可离线浏览全部内容（360° 全景源码、文物 3D 模型、非遗视频都在 `assets/` 内）。

## 页面

| 路径 | 内容 |
| --- | --- |
| `index.html` | 首页：首屏、十二城速览、生态图谱、非遗图谱、360° 全景、研学路线、知识小测 |
| `map.html` | 内蒙古城市地图，进入十二盟市 |
| `hall.html` | 3D 文物展厅 |
| `cities/*.html` | 12 个盟市详情页（景点、非遗、路线建议） |

## 交互功能

- **360° 全景**：球面全景浏览，可拖动、语音讲解、陀螺仪
- **VR 护照**：每打开一个全景盖一枚章，集满 5 枚解锁「北疆 VR 研学证书」
- **证书打印**：一键打印为单页 A4 横向，日期取当天，编号随机
- **研学路线**：按天数与偏好生成行程，可打印
- **知识小测**：10 道题与即时应答
- **吉祥物**：首屏动图向导，点击可问答

## 目录

```
index.html / map.html / hall.html
cities/          十二盟市页面
css/pangu.css    全站样式（含打印样式）
js/              全景、3D、路线、护照、吉祥物等脚本
assets/img       图片、全景图
assets/models    3D 模型
assets/video     非遗视频
```

## 说明

- 教学与公益用途；地图边界基于公开地理数据简化绘制。
- 字体走 Google Fonts CDN，离线时自动回退系统字体，不影响功能。
- 手机陀螺仪、语音朗读需要浏览器授权；`file://` 下部分浏览器会限制这些能力，部署到 HTTPS 后可正常使用。
